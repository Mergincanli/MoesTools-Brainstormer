# Games registry, batch r3: notes

Entries written to `games_r3.json`: `generals` (Command & Conquer: Generals with Zero Hour), `tempest-rising` (Tempest Rising with the Veti) and `iron-harvest` (Iron Harvest with Rusviet Revolution and Operation Eagle). `check_games.py` prints OK. A six-word copy-check of every note against all the pages read found no shared runs.

## Choices that need a look

1. **Generals tiers follow the wiki's own labels.** Generals has only one tech building per side (USA Strategy Center, Chinese Propaganda Center, GLA Palace). Units can also be unlocked by a General's Promotion. The wiki's infoboxes give tier 3 to units behind the tech building (Overlord, Hacker, Super Hacker) and tier 2 to a unit unlocked only by a promotion (Marauder tank, https://cnc.fandom.com/wiki/Marauder_tank). The map follows that:
   - **t1:** basic production (Command Center, Supply Center, Supply Stash, Barracks, War Factory, Arms Dealer, Airfield).
   - **t2:** a promotion alone (Paladin, Stealth Fighter, Marauder at 1-star; Pathfinder at 3-star).
   - **t3:** the tech building, alone or with a promotion (Nuke Cannon, SCUD Launcher, Hijacker).

   This puts the heroes (Burton, Black Lotus, Jarmen Kell), the Overlord and the Aurora at t3, like RA3's heroes and Apocalypse Tank. It also puts some modest specialists at t3: Rocket Buggy, Angry Mob, Bomb Truck, Battle Bus, Avenger, ECM Tank, Microwave Tank, Hacker and Saboteur. The other reading (tech building at t2, tech building plus promotion at t3) fits the "one tech building" wording too, but it would leave t3 almost empty, with only three units. Decide whether to keep this map.
2. **Three generals get a promotion unit without spending a point.** Granger gets the Stealth Fighter, Tao the Nuke Cannon and Kassad the Hijacker. The unit is recorded under its main faction, so use the main faction's gate and mention the exception in its notes. Only Granger's Stealth Fighter would change band (t2 to t1).
3. **Promotion gate names.** The wiki writes "General's Promotion Level 1". The gates say "1-star General's Promotion" and "3-star General's Promotion", matching the star ranks shown in the game. Composite gates read "Palace and 1-star General's Promotion" and so on.
4. **Faction tags on gates.** Generals and Iron Harvest gates carry no faction tag. In Generals every building is shared by a main faction and its three generals; in Iron Harvest all four factions and `shared` use the same building names. The validator accepts a tagged gate only for exactly the unit's faction, so a `usa` tag would reject a `usa-laser` unit (the same issue r1 raised). Tempest Rising has no subfactions, so its gates are tagged, and "Barracks" appears twice (gdf, dynasty).
5. **Leang (the Boss General) is left out.** She is not a normal skirmish side.
6. **No `introduced_in` on the Veti.** The Veti became playable in skirmish and multiplayer through the free patch 2.0.0+60710 (29 September 2026). It came out the same day as The Veti's Wrath, a campaign expansion, and every owner of the base game has them. If you would rather flag Veti units as late additions, set `introduced_in: tempest-rising-vetis-wrath` on the faction.
7. **Tempest Rising half-tiers.** The wiki's "tier 2.5" steps (Satellite Uplink pods, the Dynasty Bastion, a Veti Eye tethered to an Initial or Elevated anchor) stay in t2. Its "tier 3.5" steps (Data Core pods, Transcendent tethers) stay in t3. The Tier page lists "Veti Eye with Elevated Awakening" under both 2.5 and 3.5. The unit pages put its units (Golem, Constellation) at tier 2, so the map does too.
8. **Iron Harvest `shared`.** It covers the common aircraft that every faction builds (Skybike, Airlift, Gunship). It also covers the weapon systems (Field Cannon, Heavy MG, Mortar): the wiki says every faction uses the same designs with its own crew, although it has a page per faction. Rusviet Revolution added only a four-mission campaign and no units. Operation Eagle added Usonia, plus the common aircraft and anti-air for everyone (free for all players), so set `introduced_in: iron-harvest-operation-eagle` on those units.
9. **Flavour.**
   - Generals: USA allied (lasers, drones, stealth, precision) and China soviet (tank hordes, Overlord, nukes, propaganda). The generals inherit their parent's flavour. The GLA (guerrilla, toxins, salvage, tunnels) fits none.
   - Tempest Rising: GDF allied (marking, drones, lasers, intel) and Dynasty soviet (Eurasian bloc, brute force, Voltaic electric weapons, the crushing Tempest Sphere). The Veti fit none.
   - Iron Harvest: Rusviet soviet. Usonia allied is a judgement call (air power, drones, the best-equipped army); drop it if "clearly" should be stricter. Polania and Saxony fit none.
10. **Franchise names.** Tempest Rising shares its universe with Bombshell and Ion Fury, and Iron Harvest shares the World of 1920+ setting with the board game Scythe. Neither link matters for counting, because no other researched game is in those series, so the franchise is the game's own name.

## Damage and armour maps (not in `sources` because of the 1-4 guide)

- **Generals damage.**
  - **Source.** The keys are the INI names from EA's released Zero Hour source code, file Damage.h, read from https://raw.githubusercontent.com/electronicarts/CnC_Generals_Zero_Hour/main/GeneralsMD/Code/GameEngine/Include/GameLogic/Damage.h. github.com itself is blocked from this session; the raw file loads. Wiki infoboxes write the same names in words, for example "(Armor Piercing)".
  - **MICROWAVE maps to energy.** The code describes it as radiation that hurts only infantry, but it leaves no lingering zone, so toxic does not fit.
  - **SUBDUAL types map to emp.** The code uses them for effects that disable rather than kill, the kind the ECM Tank (vehicles) and the Microwave Tank (buildings) produce.
  - **Left out:** CRUSH, KILLPILOT (Jarmen Kell's pilot snipe; record it as an ability), HACK, SURRENDER, DEPLOY, WATER, FALLING, PENALTY, DISARM, HAZARD_CLEANUP, TOPPLING, UNRESISTABLE, KILL_GARRISONED, STATUS and SUBDUAL_UNRESISTABLE.
- **Generals armour.** Names are as written in the wiki's `armortype` field. Exceptions:
  - The drones use Tank Armor; record them as light.
  - The Overlord and Emperor Overlord are super-heavy by size.
  - One-off sets (Dozer, Toxin Truck, QuadCannon, Avenger, Sentry Drone, Battle Bus, Assault Crawler) map by what the unit is.
- **Generals damage: which step decides** (armament[].damage).
  - **Step 4 binds.** The damage_map applies to Generals. The wiki's UnitBox gives each weapon's numbers in its `groundattack` and `airattack` lines, which the template takes from the game data, and ends each line with the damage name in brackets, written out in words. That name is the weapon's category. Weapon.ini in the unedited 1.04 files (see Generals official role lines below) has the same name as `DamageType`.
  - **Steps 1 and 2 still come first.** A weapon that does no damage at all, because it only hacks, jams, marks a target or cleans up toxins, takes step 2, even when its name is a map key (the SUBDUAL names).
  - **Two names, no single category.** A weapon the sources give two names, such as a shell plus the toxin or radiation field it leaves, or one name against ground targets and another against aircraft, goes to step 5.
  - **Rotary guns.** GATTLING and SMALL_ARMS are bullet categories: a rotary gun that deals either fires bullets, so it is a machine gun (the weapon-families tie-break between machine guns, autocannons and cannons). COMANCHE_VULCAN is not decided here; go by what the sources say the gun fires.
- **Generals armour: steps 1 and 2** (the armour-class order).
  - **Step 1** (the armour_map, with the exceptions in the bullet above) decides for every set the map lists.
  - **Step 2 never applies.** Each Generals unit has a named armour set (Human Armor, Tank Armor and so on), never a bare light, medium or heavy, so a set the map leaves out goes on to step 3, then step 4.
  - **Soldiers.** Armor.ini in the 1.04 files has several human sets besides Human Armor, and the wiki's `armortype` field names some of them (for example Chem-Suit Human Armor). For the soldier rule, a set is tougher armour than the basic rifle infantry's only when it lets less gunfire through than Human Armor does (its SMALL_ARMS, GATTLING or COMANCHE_VULCAN lines); then the soldier is light. A set that differs only against fire, lasers, toxins, radiation or microwaves leaves the soldier unarmoured; say so in armour.notes.
- **Tempest Rising damage.** These are the seven types on the wiki's Damage page; Omni (ignores armour) is left out. Every laser weapon is energy, whatever its category (Cannon for most, Explosive for the Comms Officer's). Named exception (step 3 under armament[].damage).
- **Tempest Rising armour.** Medium vehicle maps to heavy, because the two main battle tanks are Medium vehicles and our heavy class is for main battle tanks. Heavy vehicle also maps to heavy. Lift the biggest units (Tempest Sphere, War Ender) to super-heavy by size. Units also have six armour percentages, but the label is enough for the class.
- **Iron Harvest damage.** No `damage_map`: each weapon lists a damage value per armour class, and there are no named damage types.
- **Iron Harvest armour.** Unarmored, Light, Medium and Heavy (plus Structure), shifted one step up to match our definitions:
  - Light maps to medium: light walkers and exosuits are our "light walkers, power suits".
  - Medium maps to heavy: most battle mechs, including the anchor Lowca and Knox.
  - Heavy maps to heavy.
  - The mega mechs and the Samson are super-heavy by size.
  - Aircraft are exceptions: record the Skybike and Revere as light, whatever their label.

## Official role lines

Written in batch R3 preparation, before any unit of these games was coded, and checked against the sources by a second researcher. Roles step 1 reads this text first; roles step 4 and the roles.secondary drop rule read its strong-against and weak-against wording.

### Command & Conquer: Generals (`generals`)

From the Generals manual scan (all three sides' unit tables), the Zero Hour manual scan, the build tooltips and hints in the unedited Zero Hour 1.04 game files and the wiki's unit pages.

- **Designation (roles step 1): the Purpose entry.** The base game's manual gives nearly every base-game unit a short Purpose entry next to its description, such as "Purpose: Builder" or "Purpose: Siege". Read it as the unit's designation. Many entries are phrases that match no role label or alias, and those name no role. Entries built on the word Assault (Tank/Structure Assault, Base/Unit Assault) are among them.
  - **Where to read it.** The wiki's transcript (page Command & Conquer: Generals manual) keeps the USA and China unit tables with these entries but drops the GLA table. The scan has all three sides. Its File page returns only a licence template through the API, so open the PDF itself: https://static.wikia.nocookie.net/cnc_gamepedia_en/images/b/b8/Command_and_Conquer_-_Generals_-_UK_Manual_-_PC.pdf/revision/latest. The unit tables are on printed pages 27 to 29 (USA), 34 to 36 (China) and 40 to 42 (GLA), the PDF's page numbers too. Read the page images or a layout text dump, because a plain dump mixes the two columns. Cite the PDF as kind official, with a note that the wiki hosts the scan; the copy-check cannot read a PDF, so check paraphrases of it by hand.
  - **Entries that name a role** (label or alias, in any word form): Builder (engineer: both Construction Dozers, the Worker); Anti-Infantry (Ranger, Path Finder, Red Guard, Dragon Tank, Gattling Tank, Rebel, Technical, Angry Mob, Toxin Tractor); Anti-Tank and Anti-Vehicle, both anti-armour (Missile Defender, Tank Hunter, RPG Trooper, Terrorist, Scorpion, Marauder; Anti-Vehicle on the Hijacker); Anti-Air (Missile Defender, Tank Hunter, RPG Trooper, Quad Cannon); Scout (Path Finder, Colonel Burton, Black Lotus, Jarmen Kell, Raptor, Comanche, MiG); Siege (Tomahawk, Inferno Cannon, Nuke Cannon, Rocket Buggy, SCUD Launcher); Transport (Humvee, Chinook, Troop Crawler, Technical); Supply Collector, logistics (Chinook, Supply Truck, Worker); Healer, support (Ambulance); Base Infiltration, infiltrator (Colonel Burton, Black Lotus, Jarmen Kell).
  - **Entries that name none:** Urban Terrain Acquisition, Veterancy Transfer (Pilot), Clear Garrisoned Structures, Clears Toxin, Quick Hit Attacks (Humvee: not a form of raider's alias hit-and-run), Tank/Structure Assault, Base/Unit Assault, Base Assault, Anti-Structure, Neutralise Enemy Structures, Detect stealth, Radar and Surveillance.
  - **Collect Funds** (the Hacker, next to Neutralise Enemy Structures) is read here as a form of logistics' alias collector, since the Hacker earns the money by its own action. When you code the Hacker, add an uncertain entry at roles that names this reading.
  - **Tags in the name cell** are not role text: "(Structure Upgrade)" marks a unit the tech building unlocks, "(Generals Ability)" one a General's Promotion unlocks (the Nuke Cannon and SCUD Launcher carry both), and "(non-trainable)", on the Pilot alone, a unit no building trains.
- **Zero Hour units have no designation.** The Zero Hour manual (the wiki's transcript, and the 2015 scan the wiki hosts, https://static.wikia.nocookie.net/cnc_gamepedia_en/images/b/b1/CNC_Generals_Zero_Hour_Manual_2015.pdf/revision/latest) gives descriptions but no Purpose entries. Use the opening line of the unit's build tooltip as its official one-line description, when it has one. That holds for the generals' units of their own too (see Generals' versions).
  - **Opening lines that name a role:** Transport (Listening Outpost, Attack Outpost); Assault Transport (Assault Troop Transport, and the Combat Chinook, whose line also collects supplies, so logistics too); heavy lift transport (Helix) and heavy lift assault transport (Assault Helix); infiltration unit (Saboteur, infiltrator).
  - **Lines that name none:** Avenger, Sentry Drone (detects stealth), Combat Cycle (fast and versatile), Battle Bus (it loads infantry, but the line has no transport word), King Raptor, Toxin Rebel, Toxin Terrorist and Aurora Alpha Bomber.
  - **No opening line:** the Microwave Tank, ECM Tank, Emperor, Mini-Gunner and Laser Tank. For these, step 1 reads the unit's entry in the Zero Hour manual instead, all of it, as the Red Alert 1 and 3 notes read a manual paragraph when nothing shorter exists (games-r1.md). The Microwave Tank's and the ECM Tank's entries say they disable electronics, a word form of the disabler label; the other three name no role.
- **Build tooltips have strong-against and weak-against lines.** In the game's 1.04 string table, most combat units' build tooltip is a "Strong vs." line and a "Weak vs." line, sometimes after a short line on what the unit does. Roles.primary step 4 and the secondary candidates read the Strong vs. line, and the secondary rule that drops a role reads the Weak vs. line.
  - **Target words.** Tanks, vehicles and light vehicles are armour; infantry of any kind (missile-armed infantry, rocket soldiers) is infantry; aircraft, air, fighters and enemy fighters are air. These match none of the three anti roles: buildings, base defenses and enemy base defenses, missiles, rockets (the Paladin's strong line, the Emperor's weak line), scouts, anti-air units and defenses, and the Angry Mob's weak line (flame, toxins, flash-bang grenades).
  - **Only one of the two lines:** the Listening Outpost and the Combat Cycle have only a Weak vs. line, the Battle Bus only a Strong vs. line. Description only: both Construction Dozers, the Worker, the Supply Truck, the Chinook and Combat Chinook, the Ambulance, the Radar Van, the Saboteur and the Toxin Terrorist.
- **The manuals' descriptions count too.** Both manuals' unit descriptions are official text, so roles step 4 and the drop rule read their strong and weak words as well, with the same target words. A role word in them counts at roles.secondary step 1 (the Zero Hour manual rates the Combat Cycle highly for reconnaissance: scout). Examples from the Generals manual: the Gattling Tank's gun is deadly to infantry and lightly protected targets (infantry); the Dragon Tank works very well against soldiers, garrisoned ones included (infantry). A named enemy unit (the Raptor's weakness to Chinese MiGs) matches no anti role.
- **Hints count too.** The same string table holds 82 hints (labels starting `HELP:`, in the binary original too), most of them on Zero Hour's new units, upgrades and powers. They are the makers' words, so they are official text: roles.secondary step 1 reads a role word in them, and roles step 4 and the drop rule read their strong and weak words, with the same target words. Examples: the Emperor's calls it effective against vehicles and infantry (its tooltip names vehicles and buildings). The Toxin Terrorist's, whose tooltip and manual entry name no target, sends it against large groups of infantry. The Avenger's calls it a support unit, which counts only if it meets support's requires. Where the game shows them is unchecked. They can be out of date: the Infantry General's Black Lotus hint says you may build several, but every Black Lotus in the 1.04 files is limited to one (MaxSimultaneousOfType).
- **The wiki does not copy the tooltips.** Fewer than twenty Generals pages have Strong vs and Weak vs bullets in the UnitBox `notes` field, with no source given, and of nine compared with the 1.04 text only Jarmen Kell's matches. Treat them as the wiki's own words.
- **Wiki infobox fields.** In the UnitBox, `role` is the wiki's own label for the unit's niche, and `notes` and the prose are the wiki's words as well; `useguns` and `usearmor` describe the lore. `name`, `cost`, `time`, `hotkey`, `armortype`, `groundattack` and `airattack` come from the game, but they are names and figures, not role text. A quote box credited to the Generals or Zero Hour manual copies that manual's unit description, which is official text, but leaves the Purpose entry out. Only some unit pages have one (12 of 43 read), so read the manual itself.
- **Where to read the tooltip text.** TheSuperHackers' community patch repository keeps the unedited Zero Hour 1.04 game files in its Patch104pZH/GameFilesOriginalZH folder (its folder notes say so); the English string table there (Data/English/generals.csf) is binary. A plain-text copy is the first version of the repository's string file: https://raw.githubusercontent.com/TheSuperHackers/GeneralsGamePatch/a65f341431e95e926fca3ad7bbdce32bc6912d6d/Patch104pZH/GameFilesEdited/Data/generals.str. Every build tooltip in it matches the binary original (all 73 build-tooltip labels were decoded and compared); later versions are edited, so do not use the main branch. To find a unit's text, look up its build button in https://raw.githubusercontent.com/TheSuperHackers/GeneralsGamePatch/6c7f40d6af6a4babb77a33a4502ec7656446c13e/Patch104pZH/GameFilesOriginalZH/Data/INI/CommandButton.ini (a UNIT_BUILD button whose Object is the unit's internal name, which some wiki pages give as `internalname`; otherwise match the button's TextLabel, whose `US:` text is the unit's name with & before its hotkey letter). Its DescriptLabel names the string, and the `US:` line under that label in the string file is the English text. Cite it as kind database, with a note that it copies the in-game tooltip (see Uncertain).
- **Generals' versions.** A general's unit with its own in-game name is a unit of its own and reads only its own text, not the main unit's Purpose entry or tooltip (see Unit ids under Research notes). Every other general's unit is a version of the main unit, recorded under the main faction, and official text counts only when every version carries it. The base-game manual predates the generals; this note reads every version as carrying its main unit's Purpose entry (see Uncertain). Most versions' build buttons (their names start with the general's prefix, such as AirF_ or Nuke_) reuse the main unit's tooltip. Five have tooltip text of their own:
  - the Air Force General's Stealth Fighter, the Nuke General's Helix and the Infantry General's Hacker add or change opening words and repeat the main Strong vs. and Weak vs. lines;
  - the Demolition General's Combat Cycle is weak only against aircraft, where the main one also names tanks, so the tanks part does not count;
  - the Laser General's Aurora button points at the Microwave Tank's tooltip, a slip in the files. Read that version as neither carrying nor lacking the Aurora's lines, and add an uncertain entry naming it when you code the Aurora.
- **Official site.** The wiki's Zero Hour page links an archived copy of EA's 2004 official site (https://web.archive.org/web/20041010095143/http://www.eagames.com:80/official/cc/generals/us/home.jsp?ncc=1). web.archive.org reset every connection from this session, so whether it had unit profiles is unchecked.

## Game-wide mechanics

Mechanics that belong to the game, not the unit (see Shared mechanics and universal keys in the Conventions). Leave them off every unit's weapons and abilities. A unit that does one of them better or worse than the rest says so in its strengths or weaknesses.

### Command & Conquer: Generals (`generals`)

Written in the research run's batch preparation, before any Generals unit is coded, and checked against the sources by a second researcher. Sources: the Command & Conquer Wiki pages named below (https://cnc.fandom.com/wiki/<Title>), the Generals and Zero Hour manual scans (addresses under Official role lines), the unedited 1.04 data files (https://raw.githubusercontent.com/TheSuperHackers/GeneralsGamePatch/6c7f40d6af6a4babb77a33a4502ec7656446c13e/Patch104pZH/GameFilesOriginalZH/Data/INI/<file>; unit files under Object/, inherited modules in Default/Object.ini) and EA's released Zero Hour source code (files such as https://raw.githubusercontent.com/electronicarts/CnC_Generals_Zero_Hour/main/GeneralsMD/Code/GameEngine/Source/GameLogic/Object/Object.cpp).

- **Basic orders** (move, attack, stop, guard, attack-move, force-fire, waypoints, teams and formations, and the Retaliation option that stops units firing back on their own): every unit. No pattern. Most units' command sets in the 1.04 files carry the same Attack Move, Guard (or a Guard variant) and Stop buttons; leave those off and count only the unit's other buttons.
- **Veterancy** (earn-veterancy): every unit that fights rises through Veteran, Elite and Heroic, mainly by destroying enemies, counted by what they were worth. Elite and Heroic units also heal over time; that healing belongs to veterancy, not to an armour model or an ability. These routes are game-wide too and stay off: basic infantry rank up by capturing buildings, GLA units by picking up salvage crates, the USA Advanced Training upgrade doubles the rate, and some General's Powers and generals produce named unit types already ranked (the Veterancy and General's Promotion pages list them). The Pilot page names units that never rank up: construction dozers, Chinese supply trucks, Chinooks, Battle Buses, terrorists and saboteurs. A unit that ranks up through its own special action (the Veterancy page names Hackers stealing money, and Black Lotus stealing cash and capturing) says so in that ability's summary.
  - **More units that never rank up.** A 1.04 object ranks only when IsTrainable is set (ThingTemplate.cpp leaves it off). That adds the Ambulance, Sentry Drone, Radar Van, Hijacker, Bomb Truck, Worker, Troop Crawler, Assault Troop Transport, Listening Outpost and Attack Outpost, the vehicle drones, and the Angry Mob as a group (its members can rank). One version breaks the Pilot page's list: the Stealth General's Saboteur can rank (StealthGeneral.ini). Units that never rank up say so in weaknesses.
  - **What ranks change.** Each rank adds rate of fire, damage and health (GameData.ini). The Elite and Heroic healing is an auto-heal module every object inherits (Default/Object.ini); cite it with the Veterancy page. At Heroic the Toxin Tractor switches to its Anthrax Beta weapon (GLAVehicle.ini), which keeps the damage name and reach and only hits harder: name it in the stock weapon's summary, not as a weapon of its own.
- **Pilots** (on_death, not an ability): when a USA vehicle or aircraft that holds a rank is destroyed, a Pilot gets out, who can take that rank into another vehicle. On USA vehicles and aircraft that can rank up, code on_death pilot-eject with the rank condition in on_death.notes. No building trains Pilots.
  - **Which ones** (EjectPilotDie in the 1.04 files: from Veteran up, and never from a vehicle a Hijacker has taken): the Crusader, Paladin, Laser Tank, Humvee, Tomahawk, Avenger, Microwave Tank, Raptor, King Raptor, Stealth Fighter and Aurora; the Comanche ejects one as it crashes. A ground vehicle leaves him standing by the wreck; an aircraft drops him by parachute (Pilot page). The Ambulance, Chinooks, Sentry Drone and Dozer cannot rank, so they eject nobody.
- **Garrison** (carry-passengers, recorded on the building or vehicle, not on the riders; a vehicle whose riders fire out of it links passenger-sets-weapon instead, as Paired entries says): every infantry unit except the Angry Mob and the Pilot can enter an empty civilian building, and each side has garrison buildings of its own (Fire Base, Bunker, Palace and others). Entering, leaving and Evacuate are universal keys. A transport keeps one passive for its passenger seats (see Paired entries). A button that does more than enter, such as dropping troops into a building to clear it, is recorded on the unit that has it.
  - **Who cannot.** Every USA Pilot object is marked NO_GARRISON (1.04 files). Angry Mobs can neither garrison, ride in transports nor use tunnels, and the GPS Scrambler does not hide them (Zero Hour manual).
  - **The garrison bonus.** Soldiers inside a building fire their own weapons with about a third more reach and a quarter more damage (GameData.ini, GARRISONED). Leave it off; range bands use the soldier in the open.
  - **Inside a civilian building** soldiers cannot be sniped, and lingering fire, radiation and toxins do not reach them. The building takes the hits for them until it is down to a third of its health; then they leave it with half their health (Garrisoning page). A weapon that clears garrisons is recorded on its own unit.
  - **Carriers** (PassengersAllowedToFire in each carrier's contain module; Garrisoning page, Mobile Bunkers). Riders fire out of the Humvee, Combat Chinook, Battle Bus, Listening Outpost, Attack Outpost and Assault Troop Transport, and out of the Overlord's and Helix's Battle Bunker add-ons: passenger-sets-weapon. The Combat Cycle's one rider drives it and sets its weapon: passenger-sets-weapon too. Riders sit as cargo in the Chinook, Troop Crawler, Technical and Ambulance, and in the Helix without its bunker: carry-passengers.
  - **Riders when the carrier dies.** Each carrier sets the share of their full health its riders lose, as damage nothing resists (DamagePercentToUnits in its contain module; OpenContain.cpp); the ones who live get out. All of it, so they die, in the Humvee, both Chinooks, the Helix (with or without its bunker) and the Combat Cycle: say so in on_death.notes. Half in the Overlord's Battle Bunker, the Assault Troop Transport and the Attack Outpost, and a tenth in the Troop Crawler, Listening Outpost, Technical and Ambulance: their riders get out hurt, which is bail-out, basis in-game, with "only when riders are aboard" in on_death.notes. The Garrisoning page gives the Listening Outpost's riders half their health instead: add an uncertain entry marked sources_disagree there. The Battle Bus first turns into a bunker (Battle bus page).
- **Tunnel Networks** (build-linked-exits, recorded on the structure): GLA ground units, vehicles included, can go into one Tunnel Network and come out of another, and heal while inside. The Zero Hour manual says Angry Mobs cannot. Leave it off the units. Units inside cannot fire out, and all of them die when the last network falls (Tunnel network page).
- **Taking over an empty vehicle** (recover-wreck): a vehicle whose crew has been killed turns neutral, and any infantry unit can climb in and claim it (Neutron shells and Pilot pages). Leave it off the infantry; a weapon that kills crews is recorded on its own unit. Neutron Mines empty vehicles the same way (Zero Hour manual), and a vehicle with no crew crushes nobody (Object.cpp, canCrushOrSquish).
- **Crates** (picking up is a universal key): any unit can collect the money crates found on the battlefield; they give only money, unless a map maker sets one to give a vehicle (UN Crates page). Leave them off.
  - **Salvage crates.** One drops when a GLA unit destroys a ground vehicle (Crate.ini: the killer must be a GLA salvager, which every GLA unit is; aircraft drop none). The Salvaging page also has one drop when the enemy destroys a GLA vehicle; the 1.04 data does not show that, so where it matters, add an uncertain entry marked sources_disagree. Only GLA units see and collect them, and they vanish after about half a minute. Every ground vehicle can leave one, so keep it out of on_death.notes. Any other GLA unit that picks one up gets a little money or, now and then, a whole rank, which stays off.
  - **Salvage steps.** A few GLA vehicles gain fixed upgrade steps from these crates instead (the Salvaging page lists them). Record those on the vehicle: an acquired weapon for each step that changes the weapon's family and one triggered ability, both linking leech-weapon-on-kill. A step that changes only numbers (reload, range, armour) goes in notes. Such a vehicle gains no rank from crates until it has both steps (Veterancy page).
- **Repair, healing and rearming at buildings** (no pattern): every side's Barracks heals the infantry sent inside it, and the USA and Chinese War Factories and the GLA Arms Dealer repair vehicles that drive up to them. Each Air Field rearms and repairs up to four planes, a Speaker Tower heals units near it, and a captured Hospital or Repair Bay heals all of a player's infantry or vehicles wherever they are (FactionBuilding.ini; Zero Hour manual, Tech Buildings). Leave these off. The GLA Junk Repair upgrade makes every GLA vehicle repair itself: a side-wide upgrade, left off and mentioned in notes. A unit that repairs, heals or rearms others, or rearms away from an Air Field, records that on itself. The other captured tech buildings (Oil Derrick, Refinery, Artillery Platform, Reinforcement Pad) are side-wide too; prices stay the list prices.
- **Capturing buildings** (capture-structure): not game-wide. The Capture Building upgrade, bought at each side's Barracks, gives that side's basic infantry a capture button, which the Zero Hour manual says tech buildings also need. Record it on each infantry type the Capture building page lists (the Rebel and Toxin Rebel, the Ranger, the Red Guard and the Mini-Gunner), as an ability with source upgrade, linking upgrade-in-field as Paired entries says. A unit that captures without the upgrade, such as Black Lotus, records its own ability.
- **General's Powers** (bought with promotion points and launched from the Command Center): air strikes and bombs, paradrops and other drops, artillery barrages, mines, EMP and leaflet drops, spy drones, cash hacks and bounties, area repair, Frenzy and the GPS Scrambler. They stay off every unit. Powers that unlock a unit are gates in the tier_map, and powers that produce a unit type already ranked belong to veterancy. A power that gave named unit types a new button or effect would be recorded on each of them with source commander-power; the General's Promotion page lists none.
- **Side-wide upgrades and battle plans**: upgrades bought once for a whole class (armour, rate of fire, Nationalism for the horde bonus, armour-piercing ammunition, stronger toxins and the like) and the battle plans of the USA Strategy Center (more sight, armour or firepower for every unit) stay off; bands use the stock unit. An upgrade that gives named unit types a new weapon or button (flash-bang grenades, a drone or missiles bought for a vehicle, camouflage, booby traps) is recorded on each of them, as Paired entries and Stock values say. The Demolition General's Demolition upgrade gives nearly all his units and defences a detonate button and a blast on death. It reaches almost every unit of that general's side, so treat it as a side-wide upgrade: it stays off, and on_death.notes names it, as that field asks.
  - **More of them:** Countermeasures for every USA aircraft, and Chemical Suits for USA soldiers and Pilots (Zero Hour manual; Pilot page). A drone bought for a USA vehicle draws enemy anti-air fire to itself first (Zero Hour manual): say so in that drone ability's summary.
  - **Generals' starting upgrades and ranks** are side-wide too (Zero Hour manual, each general's Army Modifications): the Nuke General's tanks begin with the Uranium Shells and speed upgrades already bought, and the Toxin General's with Toxin Shells. The Tank General's tanks and the Infantry General's soldiers start ranked, the Stealth General's Rebels start camouflaged, and the Demolition General has Booby Traps from the start. A unit coded from the main faction's version names the general's difference in notes.
- **Horde Bonus**: not game-wide. The Red Guard, Tank Hunter and Mini-Gunner fire faster while at least four other allied soldiers of any kind stand close by, and the Battlemaster while at least four other Battlemasters do (HordeUpdate in the 1.04 Object files and HordeUpdate.cpp; Horde Bonus page). Record it on each of them as an innate passive. The rally-allies pattern does not fit, because no one unit gives the bonus to the rest, so leave its patterns empty and add a fit_note. Nationalism and Patriotism, which strengthen it, are side-wide upgrades.
- **Crushing** (the mobility trait crush, not an ability): vehicles run over infantry, and the wiki's UnitBox can give crusher and crushable levels. Give the trait to every ground vehicle whose crusher level is above zero (the UnitBox or the 1.04 Object file); on one smaller than large, record the size break in atypical (`mobility-traits:crush allowed.sizes medium`). The trait never decides a size. CRUSH damage is left out of the damage map.
  - **The engine's rule** (Object.cpp, canCrushOrSquish): allies are never crushed, a crusher level of zero crushes nothing, and a vehicle with no crew crushes nobody. Rank-and-file soldiers (objects with a SquishCollide module) are flattened by any crusher; anything else needs a crusher level above its own crushable level.
  - **The 1.04 levels.** Ground vehicles crush at 2 and are crushable at 2, so they flatten soldiers but not each other; the Overlord and the Emperor are 3 and 3, so only they run over other vehicles. The Sentry Drone (crusher 0) and the Combat Cycle (none set, so 0) crush nothing: no trait. Colonel Burton, Black Lotus and Jarmen Kell are crushable only at 2 and are not rank-and-file, so only the Overlord and the Emperor flatten them: the three say so in strengths (`immune:crush`, the reason naming those two).
- **Sight**: every unit and building sees around itself, and allies share what they see; the radar map is a base feature. No pattern. Stealth and stealth detection are not game-wide (see below).
  - **Fog.** Skirmish and multiplayer have no black shroud, only fog of war: ground outside every allied unit's view shows its terrain but hides enemy units and buildings (Generals manual, printed page 14).
  - **Which figure.** A unit clears the fog out to its ShroudClearingRange, the second sight figure on the wiki, which the sight band uses (registry sight_reference). Its VisionRange, the first figure, clears no fog: it is how far the unit targets, how far a detector with no detection range of its own reveals stealthed units, and how far an idle unit wakes to attack a revealed one (Object.cpp, StealthDetectorUpdate.cpp, StealthUpdate.cpp). Where the infobox gives one figure, read ShroudClearingRange in the unit's Object file; an object without one clears the fog to its VisionRange.
  - **Riders** in transports and tunnels see nothing; soldiers in a garrisoned building do (Object.cpp).
  - **Radar.** The minimap comes from the USA Command Center, from a Radar upgrade at the Chinese Command Center, or from a GLA Radar Van (1.04 files). Giving radar is not the radar sensor trait, which shows blips beyond sight.
- **Stealth and detection** (per unit; patterns cloak and disguise, sensor trait detector). Generals stealth hides a unit from enemies completely until it does what its own setting forbids (fires, moves, uses an ability or is hit, unit by unit) or an enemy detector comes near; then it hides again after a short delay. When a hidden unit is revealed, idle enemies within their own targeting range are sent to attack it (StealthUpdate in the 1.04 files). Code that as the cloak pattern on one passive ability (source innate, or upgrade where an upgrade grants it), not as the stealth sensor trait, which still lets enemies see the unit up close.
  - **Hiders (1.04 files).** Colonel Burton (seen while firing), the Pathfinder (while moving), the Sentry Drone (while moving or firing), the Stealth Fighter (while firing), Black Lotus and the Infantry General's Hacker (while using an ability), Jarmen Kell (while attacking), the Hijacker (while moving; the Stealth General's is always hidden), the Saboteur (always hidden) and the Listening Outpost (while moving or while its riders attack). By upgrade: the Rebel with Camouflage, bought at the Palace (Camouflage (upgrade) page; the Stealth General's Rebels start hidden), and the Air Force General's Comanche with its stealth upgrade. The Combat Cycle hides when its rider can. Pathfinders and Jarmen Kell can enter a building unseen (Garrisoning page). The Bomb Truck disguises itself (disguise).
  - **Detectors (1.04 files).** The Pathfinder, Black Lotus, Sentry Drone, Scout Drone, King Raptor, Troop Crawler and Assault Troop Transport, Listening Outpost and Attack Outpost, Radar Van, the Overlord's and Helix's gatling add-ons, and the Stinger Site's soldiers. Among buildings: the Strategy Center (under Search and Destroy, its page says), Patriot, Gattling Cannon and Tunnel Network. Dozers and Workers detect only mines: no detector trait. A detector cannot detect from inside a building or transport, unless its add-on says so (CanDetectWhileGarrisoned and CanDetectWhileContained).
  - **Off the units.** The GPS Scrambler, a power, switches on the stealth module every object inherits (Default/Object.ini). Camo Netting is bought on each structure: Tunnel Networks and Stinger Sites for the main GLA, every structure for the Stealth General (whose Tunnel Networks and Stinger Sites start hidden), none for the Toxin and Demolition Generals (Camo netting page). The Stealth General's netted Supply Stash also hides the gatherers working at it (same page): name it in the Worker's notes.
- **Heroes** (availability unique): Colonel Burton, Black Lotus and Jarmen Kell are limited to one at a time (MaxSimultaneousOfType in the 1.04 Object files; Burton's build tooltip shows the limit). Give the limit in tier.basis, since availability has no notes field.
- **Ammunition** (resource limited-ammo, not an ability): the Raptor and King Raptor, Stealth Fighter, Aurora and MiG fire a set load and reload only back at an Air Field (their weapons reload on return to base in Weapon.ini). Code limited-ammo on each and leave the trip home off. The Comanche reloads in the air (its tooltip), and no Helix weapon waits for a base (Weapon.ini). Each Air Field parks four planes, and a plane needs a free pad to be built (Stealth fighter page). That is no cap on the unit itself, so planes stay availability open.
- **Damaged units slow down** (no pattern): the Zero Hour manual says most units slow down when damaged and some do not. In the 1.04 files the slowdown starts once health falls to about a third (GameData.ini, UnitReallyDamagedThreshold), and units whose damaged speed equals their speed in Locomotor.ini, such as the Battlemaster and the Overlord, keep full speed. Leave it off: speed bands use full health, and the wiki's badly damaged speed is this lower figure.
- **High ground** (no pattern): the Zero Hour manual's tactics say projectile weapons reach further from raised ground. Range bands use the listed reach.
- **No retreat or reinforce order**: neither manual lists one.

- **Reinforcing** (reinforce-squad): a squad that has lost soldiers buys them back at its base or at an aid station (Infantry page; Polanian and Saxon Medic Station pages). Exosuit squads too: at base by DevBlog #30 at the latest, and at aid stations since DevBlog #43. Leave it off the squads, and record reinforce-squad only on what lets others reinforce:
  - the aid station that a veteran medic squad sets down, using itself up, or that a veteran Ward squad sets down, which stays (Usonian Medic Station page): each unit's own veteran ability;
  - the medics' Heal. Change Log #06 prices it per soldier reinforced and offers it as the field alternative to reinforcing at base, and the Infantry and Polania Republic pages agree, but the medic pages' Cons say medics cannot reinforce. Link repair-allies and reinforce-squad, with an uncertain entry marked sources_disagree.
- **Veterancy** (earn-veterancy): every unit ranks up twice, to Veteran and then Elite, from damage dealt and taken, healing or repairing, and capturing (Veterancy page); heroes have four ranks (Change Log #04). The first rank unlocks the unit's veteran ability (Veterancy and Ability pages; DevBlog #20): record it with source veterancy and the patterns of what it does. A squad keeps its rank when it swaps kits or mans a weapon system, and the crew earns the experience, not the gun (DevBlog #20), so a weapon system's rank is its crew's.
- **Fallen heroes** (downed-revive or wreck, by class): a hero brought to zero health falls unconscious instead of dying (DevBlogs #24 and #35). While down it is out of play, so no enemy can target it (patch 0.11.2). Friendly infantry and heroes on foot, an ally's included, revive it where it lies at no cost (DevBlog #35; Admiral Mason page), and the Headquarters can also bring it back (Structure page).
  - A hero coded as infantry (on foot or on horseback, or an exosuit hero coded as infantry) takes the armour model downed-revive. Say in armour.notes how it differs from the model: no enemy can finish it, and no source shows it moving while down.
  - A hero coded as a walker (a mech hero) takes on_death wreck, basis in-game: its downed machine stays on the field until a friendly unit revives it (Brunhilde's page; Change Log #20 stops mines going off for fallen mech heroes). Put the revival in on_death.notes.
  - Admiral Mason has no downed state: his airship is destroyed outright and cannot be revived in the field (DevBlog #40), and he comes back only for a fee at the Headquarters (his page). His on_death follows Wrecks; put the paid return in on_death.notes.
- **Weapon kits** (picking up is a universal key): any infantry squad can take a kit from a weapon crate or from fallen infantry and trade its whole loadout for it, becoming its own faction's unit of that type (Weapon, Weapon Crate and Infantry pages). That makes it another unit, so nothing is recorded on the squad: no acquired weapon, no ability. Mechs and some heroes cannot pick things up (Recycling Wrecks page), and since Change Log #20 Michal Sikorski can take neither weapon crates nor victory point crates.
- **Weapon systems** (field cannon, heavy MG, mortar): one design for every faction (Unit page; each faction's weapon-system pages).
  - Any infantry squad can man an abandoned or neutral one, the neutral mortars and Destroyer Cannons of some maps included (Weapon page; Change Log #08; Destroyer Cannon page). That is recover-wreck, game-wide: leave it off the infantry.
  - A built one comes crewed by five of its faction's engineers (the infoboxes; Infantry page). Three work the gun while the rest guard it; when too few are left the squad gives the gun up, and when the gun is destroyed the survivors go back to their own infantry type (Weapon System and Weapon pages).
  - on_death: bail-out (the survivors walk away as infantry) and wreck (a gun given up for lack of crew stays on the field for any squad to man), both with basis in-game, whatever class the unit is coded in. Record what the validator lists as atypical; never code the respawn default for an outcome the sources show.
  - The guns, and machine gunner squads too, must set up before they fire and then cover only a cone (KING Art's game page; Weapon System and Infantry pages): a limited-arc mount, and no deploy mode (siege's coding rule).
- **Garrisons and carriers** (carry-passengers on the building, bunker or carrier, never on the riders; passenger-sets-weapon as Paired entries says): infantry squads can garrison buildings and every faction's bunkers; exosuits cannot (Unit and Structure pages). Each carrier holds one squad, so passengers.seats is 1 and none is a transport: the Zółw, whose riders fire from inside, and Brunhilde, whose broadsides fire faster with a squad aboard (passenger-sets-weapon), and the Airlift (carry-passengers) (their pages).
- **Cover and stances** (no pattern, never evasive): infantry use low cover, kneeling behind it, and high cover, and a mech between shooter and target is cover too, since the game tracks every bullet (Cover System page; DevBlogs #20 and #21). Most cover can be destroyed, and infantry vault low obstacles (DevBlog #21; Infantry page). Lying down makes a squad harder to hit but much slower (Infantry page). Mention these in armour.notes where they matter. The engineers' sandbags, barbed wire, mines and bunkers are their own abilities (build-cover, lay-mines).
- **Mechs breaking terrain** (no pattern; not the crush trait): mechs knock down cover, fences and buildings according to their size, and flatten sandbags and barbed wire by walking over them (Unit, Mech, Sandbags and Barbwire pages; Change Log #17 for gates). Crush is for running over units, so say this in mobility.notes or strengths. Exosuits walk through barbed wire (Unit page).
- **Suppression** (no pattern): enough fire suppresses infantry, who then fire and move far more slowly, shown by an icon (DevBlog #24; Change Log #20). Change Log #20 cut suppression on weapons that are not meant to suppress and raised it on heavy machine guns, so give the weapon trait suppress only as its rule says, where a unit's own sources make pinning a main job of the weapon. An ability that lifts suppression (the Serp's) is that unit's own.
- **Melee** (no pattern): infantry fight hand to hand only when ordered with the modifier key or when attacked in melee (patch 0.11.5; the Infantry page's automatic melee is older). The plain blow every squad has (the infoboxes' melee damage lines; the Rifleman page mentions a bayonet) comes with the mechanic: leave it out of the armament, and mention it in the main weapon's summary where a source makes it matter. A melee weapon a unit is built around (the Groza's blades, the Serp's scythe, the Stark's jackhammer) is a weapon entry.
- **Rear armour** (armour model directional, never weak-point):
  - Mechs, by the game's rule: the Mech page says almost every mech takes more damage from behind, the Armor page says a hit on a weak point, often the back, does double damage, and Change Log #06 fixed, as a bug, the Polanian and Rusviet artillery mechs that lacked it. Code directional on every mech, mega mechs, wheeled mechs and mech heroes included, and say in armour.notes that hits from behind do about twice the damage. Where the mech's own page says nothing of its rear, add an uncertain entry that names the Mech page.
  - Exceptions: the Zółw has no weak spot (its page). The Mocny's page says it has no rear weakness, but that line was written in early October 2020, before the Change Log #06 fix (22 October 2020): code directional, with an uncertain entry marked sources_disagree.
  - Also directional: the weapon systems, whose shields guard the crew from the front while side and rear hits do full damage (the field cannon, heavy MG and mortar pages), and Admiral Mason, whose Flagship prow cuts the harm of hits from ahead (his page). No source gives it to infantry, exosuits or the other aircraft.
- **No friendly fire**: no weapon hurts friendly units, mines included (Damage page; Mine page). Never code the weapon trait friendly-fire.
- **Wrecks** (on_death wreck, basis in-game, for mechs and airships): a destroyed mech or airship leaves a wreck that nearly any infantry squad can recycle for a little iron and oil, which allies share (Recycling Wrecks page; DevBlog #24; Change Log #04). Exosuits leave none. Recycling is gather-resources through the universal pick-up action: game-wide, so leave it off the infantry. A mech or exosuit walking over a wreck, or an explosion, removes it: say so in on_death.notes where it matters.
- **Capturing points** (a game rule; no pattern): infantry and exosuit squads take resource buildings and victory points, neutral or enemy (Capturing Buildings page; Unit page); mechs cannot. Leave it off.
- **Crates** (opening one is the universal pick-up key): iron and oil crates, weapon crates that always hold the same kit (Iron Crate, Oil Crate and Weapon Crate pages), and the victory point crates of the Drop Zone mode (Drop Zone page). Leave them off.
- **The Reserve** (a side-wide call-in; no pattern): before the match each player picks a hero and fills two reserves from the faction's roster. In the match each reserve is called in from the Headquarters for resources, cheaper than building its units, and lifts the population cap (DevBlog #27; patch 0.11.5; DevBlog #35). Leave the reserve off every unit: a unit that can also be built takes its production gate and price. Heroes come only through it (research notes).
- **No side-wide powers or unit upgrades**: KING Art ruled out off-map abilities (DevBlog #21), and the reserve is the only side-wide call-in found. The sources name no researched or bought upgrade for units, only building upgrades (Building Upgrade page; DevBlog #21). So no ability takes source commander-power, and source upgrade only where a unit's own sources show an upgrade bought for it.
  - Call-ins that belong to a unit are its own abilities: the Attucks's veteran Rapid Insertion, the Groza's Airborne Reinforcements, Princess Sita's Shadow Strike and William Mason's Requisition (their pages). A call-in that a building makes (the Usonian Paratrooper Bunker's paratroopers) belongs to the building.
- **Repair and healing at base** (no pattern): mechs are repaired at the base for resources and on a cooldown (DevBlogs #27 and #30), and heroes and exosuits are healed there for resources (Change Log #04; patch 0.11.5). Leave base repair off. Field repair and healing belong to the units that give them: engineers repair mechs, exosuits, buildings and weapon systems, and medics heal infantry, exosuits and heroes, allies' units included (Repair and Unit pages; Change Logs #04, #06 and #19): repair-allies on each.
- **Fog of war** (no pattern): a standard fog of war in which buildings do not block sight (Fog of War page; DevBlog #21). The short reveal around a destroyed mech (Change Log #10) or a downed hero (DevBlog #35) stays off.
- **Stealth and detection** (per unit): Olga's camouflage, the Attucks's canopy, Princess Sita's hawk and the Hashashin she calls in hide from enemies, the first two until enemies come close or they act (their pages). Code each from its own sources (cloak, or the sensor trait stealth). No page names a unit that sees hidden units, so none gets the detector trait; the fog-of-war reveals of the Erlkönig's flare, Gunter's wolves and Sita's hawk are those units' own abilities.

### Command & Conquer: Generals (`generals`)

- **Unit ids and units of their own.** The slug is the unit's in-game name: the DisplayName in its 1.04 Object file, read in the string table (an `OBJECT:` label). It can differ from the wiki's page name and from the build button. Examples: `generals.usa.crusader` (page Crusader tank), `generals.usa-laser.laser-tank` (page Laser Crusader), `generals.china-tank.emperor` (page Emperor Overlord tank; its build button says Emperor Overlord), `generals.gla.jarmen-kell`.
  - A general's unit with its own in-game name is a unit of its own, under that general's faction: the King Raptor and Combat Chinook (Air Force), the Laser Tank (Laser), the Aurora Alpha Bomber (Superweapon), the Mini-Gunner, Attack Outpost, Assault Troop Transport and Assault Helix (Infantry), the Emperor (Tank), and the Toxin Rebel and Toxin Terrorist (Toxin).
  - Every other general's unit keeps the main unit's name and is a version of it, recorded under the main faction with its differences in notes. The Infantry General's Hacker is one, although the wiki gives it a page of its own (Super hacker).
- **Tier gates.** Read each unit's gate from the Prerequisites block of its 1.04 Object file (Object lines and a Science line); what a factory really offers is its CommandSet in CommandSet.ini.
  - Two units that the batch note's choice 1 lists at t3 need no tech building: the Avenger needs only the War Factory (its Strategy Center line is commented out; only the Air Force General's Avenger needs one), and the Saboteur only the Barracks once an Arms Dealer stands.
  - Three generals get a promotion unit with no point to spend, and two of them need less than the main gate: the Air Force General's Stealth Fighter needs only the Air Field, and the Stealth General's Hijacker only the Barracks (no Palace either). The Nuke General's Nuke Cannon still needs the Propaganda Center. Record each under the main faction's gate and name the exception in tier.basis.
- **Who lacks what** (1.04 command sets; name these generals in tier.basis). Air Force and Superweapon Generals: no Crusader or Paladin. Laser General: the Laser Tank instead of the Crusader, and no Paladin or Tomahawk. Infantry General: the Mini-Gunner instead of the Red Guard; no Battlemaster, Overlord or Gattling Tank; his own Assault Troop Transport, Attack Outpost and Assault Helix in place of the Troop Crawler, Listening Outpost and Helix. Tank General: the Emperor instead of the Overlord; no Inferno Cannon or Nuke Cannon. Nuke General: the full Chinese list. Toxin and Demolition Generals: no Hijacker or Saboteur. Stealth General: no Scorpion, Marauder or SCUD Launcher. The Air Force General's Supply Center builds both the Chinook and the Combat Chinook, which also needs a War Factory.
  - An object in a general's file is no proof that he fields it: unused buttons exist for a Demolition Hijacker, Superweapon Crusader and Paladin, Laser Paladin, Infantry Gattling Tank, Stealth SCUD Launcher and Air Force Battle Drone.
- **The 1.04 files** (https://raw.githubusercontent.com/TheSuperHackers/GeneralsGamePatch/6c7f40d6af6a4babb77a33a4502ec7656446c13e/Patch104pZH/GameFilesOriginalZH/Data/INI/<file>). Units are in the Object folder: AmericaInfantry.ini, AmericaVehicle.ini, AmericaAir.ini and AmericaMiscUnit.ini, the China and GLA files named the same way, and one file per general (AirforceGeneral.ini, LaserGeneral.ini, SuperWeaponGeneral.ini, InfantryGeneral.ini, NukeGeneral.ini, TankGeneral.ini, ChemicalGeneral.ini, DemoGeneral.ini, StealthGeneral.ini), whose objects carry the general's prefix. The main factions' buildings are in FactionBuilding.ini, and modules every object inherits are in Default/Object.ini.
  - Read them to check figures, buttons and tooltip labels, and where these notes send you to them (Armor.ini sets for the soldier rule, Weapon.ini's DamageType to confirm a damage name, and the facts the Game-wide mechanics take from them). Any other term only they would set (friendly-fire from a blast that hurts allies, magazine from a clip size, auto-target from an add-on's own AI) is not set; mention the fact in notes.
- **Speed.** The wiki's land speed is the locomotor's Speed, a distance per second, and a unit reaches it on open ground (INI.cpp, Locomotor.cpp and PhysicsUpdate.cpp in EA's code), so the Ranger's 20 is its real top speed. Colonel Burton, the Saboteur and the Combat Cycle can also move on cliffs (cliff locomotors in Locomotor.ini; the Zero Hour manual says so for the Saboteur). Code the climb trait where a cited page shows the unit going up cliffs (the Combat Cycle's hint mentions only jumping off them). Burton and the Saboteur slow down on steep climbs, which the bands ignore.
- **Sight.** With the fog figure (registry sight_reference), no factory-built unit bands long: the highest, 600 (Aurora, Comanche, Chinook, Helix), is exactly 1.5 times the Ranger's 400, so medium. The units at 200 band short: the Red Guard, Mini-Gunner, Dragon Tank, Overlord, Emperor, Tomahawk, USA Dozer, Worker, Terrorist, Hijacker, Toxin Tractor, Bomb Truck and Battle Bus. So does the Angry Mob, at 150.
- **Damage names: traps** (armament[].damage, with Generals damage above).
  - **Step 3 exception: the Angry Mob.** Its pistols, AK-47s and thrown rocks carry MOLOTOV_COCKTAIL, like its Molotov cocktails (Weapon.ini; the wiki's infobox repeats it). Record the guns and the rocks as kinetic; only the Molotovs are fire. Every other damage name a Generals weapon uses is a map key or on the left-out list, and a left-out name goes to step 5.
  - **No laser exception.** Unlike Tempest Rising, Generals has no rule that makes lasers energy, so step 4 binds: the Laser Tank's gun carries ARMOR_PIERCING (armour-piercing) and the Avenger's anti-air lasers SMALL_ARMS (kinetic; its wiki airattack line says Small Arms too). LASER appears only on point-defense lasers (on the Paladin, the Avenger, the Air Force General's planes and the Superweapon General's drone), which shoot down missiles: the interceptor armour model, not weapons.
  - **SURRENDER** is on the left-out list, but the Ranger's flash-bang grenade does real damage with it, to soldiers only (Armor.ini lets vehicles take none). The wiki writes it as Surrender. Step 5 decides.
  - **The MiG's** napalm missile carries JET_MISSILES (armour-piercing by the map) and its Black Napalm version EXPLOSION, and both start a FLAME firestorm. Where its sources give the missile and the fire as two names, step 5 decides (Two names, above).
  - **Where some names sit.** The Technical's machine gun and its salvaged cannon both carry GATTLING. COMANCHE_VULCAN is on the Sentry Drone's gun, the Humvee's gun, the Comanche's cannon and the Helix's minigun. The left-out KILLPILOT is spelled KILL_PILOT in Weapon.ini and Armor.ini.
- **Armour sets: traps** (armour-class step 1).
  - The wiki's `armortype` field spells sets several ways (Tank, TankArmor, Tank Armor; Truck, Truck Armor; Toxin Truck; QuadCannonArmor; Assault Crawler; Low for the Angry Mob): read each as the 1.04 set it names.
  - The Dragon Tank's page says Tank Armor, but in 1.04 it has a set of its own, DragonTankArmor: it takes no fire damage, more from gattling guns, and a fifth from infantry missiles and Molotovs, which Tank Armor takes in full (Armor.ini). Treat it as one more one-off set that maps by what the unit is, and add an uncertain entry marked sources_disagree.
  - The Ambulance shares the Toxin Truck set, and the Air Force General's Comanche has a set of its own (AFG_ComancheArmor). The generals' own soldier sets (InfGen_HumanArmor, ChemReb_HumanArmor, DemoGenTerroristArmor) go through the soldier rule above.
- **Promotion ranks.** In a General's Power tooltip, Rank 1 to 3 is the power's own level, bought with more points, not the general's star rank (1.04 string table). The game names the star ranks 1 Star General to 5 Star General.
- **Not a skirmish unit.** The main USA Barracks command set lists a Bio-Hazard Technician, but the wiki's Biohazard Technician page calls it campaign-only and impossible to train or select. Do not research it.
- **Page names.** "Paladin tank" and "Rocket buggy" lead to disambiguation pages: use "Paladin tank (Generals)" and "Rocket buggy (Generals 1)". "Colonel Burton" redirects to "Burton". The Hacker and Aurora pages have no "(Generals 1)". The Demolition General's upgrade page is "Demolition" (the game calls it Demolitions). Search the API first.
